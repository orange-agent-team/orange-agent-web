# 个人文本模型任务

入口`/tasks`。当前范围是个人预算下的文本推理任务，包含可用模型目录、原输入上传、可信报价、用户确认、提交与输入绑定、只读恢复、任务状态/取消、费用与纯文本结果。它不提供完整Web Agent、多轮工具执行、云工作区或支付。

契约快照0.3.0固定服务端`bd896b70b598f45f22beae5ec2cc7977fec915da`，新增artifacts/pricing共四份文件。金额用严格字符串和BigInt；余额/预算预检查不能替代服务端事务冻结。报价不会消费积分，只有当前会话中新取得的原报价能产生内存中的确认对象；本地confirmed标记不能自行发起提交。

sessionStorage仅保存当前user/owner归属的原参数、对象描述符、报价及请求编号，不保存提示词、结果或凭证。恢复先按原Invocation只读查询；已有Job不重跑模型，404不等于旧请求已失败，不自动换键。原参数、对象和报价不可覆盖。批准尝试在首个await前记录，撤回标记阻止迟到的异步继续提交；清除后的记录不能被旧回调重新创建。

未提交输入可按原ID删除。已确认却尚未读到Job时，必须向服务端撤回原SubmitJob请求，只有当前用户/owner/Invocation/quote均匹配的prevented回执才能终结待核对状态。服务端未返回明确回执时仍保留原记录。已有Job继续使用真实取消/结算结果；回执不证明GPU释放，也不虚构退款。关闭标签页不自动取消已接受任务，任务事实以服务端列表为准。

模型结果必须是专用`application/vnd.orange.model-response+json`，并校验精确版本、长度（最多1MiB）、SHA、UTF8和严格结构。这里只接受无工具调用的文本，不执行HTML/脚本/工具。内容删除或权限拒绝清除展示内容，不把单一内容403当作登录失效并循环重登。执行与结算分别显示；succeeded/settled不意味着GPU回收已被认证。

`node scripts/check-model-tasks.mjs`运行客户端、构建和真实Chrome/API替身验证。实际链路由服务端`check-web-compute.py --web-repo <本仓库>`运行独立API/Worker/固定CPU模型/Counter/PG和Chrome，再用独立Counter核对真实计量、一次结算、CPU关闭及删除后的内容拒绝。该套测试的用户会话、价格和登记准入是显式夹具；普通真实OIDC仍由独立USER-OIDC验收覆盖。

已保留两次发现的失败：加载图标污染按钮可访问名称；真实输出的专用MIME被误当普通JSON。修复保留原断言，并增加稳定名称/忙碌状态与普通JSON不得冒充模型输出的检查。前一模型切片22客户端、4 Chrome替身、实际浏览器/模型组合及关联回归已通过。本次新增服务端撤回屏障后，客户端增至24项，4 Chrome替身、实际浏览器/模型组合及全部源码绑定关联回归已通过；不代表整个项目或原父任务完成。

## 文本上传前的本机核对

打开任务页时默认仅在当前浏览器编辑。选择允许上传原文或遮盖后上传，再生成一次本机预览；预览展示原请求编号、模型版本、实际输入、输出上限、字节数和 SHA-256。用户确认上传后，平台先接收这份已核对的字节以计算报价。下一次确认才提交模型任务。浏览器编辑、生成预览和调整规则均可在任何输入上传前进行。刷新后，草稿原文、遮盖词和本机预览会消失。

规则为逐行、区分大小写的字面片段，最多 32 项，每项最多 256 个 UTF-16 单元。重叠时优先较长的匹配，替换为固定的“[已遮盖]”。供应节点仍能读取实际输入，未匹配的个人信息和上下文线索可能保留。文本修改、预算或模型切换、修改遮盖规则都会使预览失效。恢复一笔尚缺原文的上传时，重新生成的字节必须与原请求的摘要和大小一致。用户仍可独立撤回尚未提交的输入。

## 报价与根预算

个人文本、个人或团队转写，以及托管 Agent 的各次模型调用均在提交前读取原报价的资金快照。界面显示付款账户、模型或价格版本、本次最高预留、根预算总额、累计消费、已预留及剩余金额。团队普通成员使用分配给自己的预算，并可查看该报价能否支付。团队钱包总额只对有权查看的请求人显示。每个续段继续使用原根预算，上一回合的消费计入下次可用额度。

关闭预算、原报价过期、原支付存在争议、余额不足或预算不足会阻止确认。刷新重新核对原报价。音频预检显示上传目的账户和选定文件，远程转写授权另行显示节点、地区、模型和原音频版本。确认提交后，服务端在同一事务重新核对当前资金及授权。

## 团队成员文本推理

从组织页中分配给自己的生效预算进入“使用这笔团队预算运行文本任务”。输入默认留在浏览器。选择原文或规则遮盖并批准上传后，平台才能为该版本计量和报价。提交前显示团队标识、根预算、剩余额度和本次最高预留。普通成员可以核对报价支付条件，团队钱包余额按财务权限显示。

切换到个人任务页会切换恢复记录。团队文本恢复键包含成员、组织和预算，重新进入原预算会读取原报价并要求单独确认提交。结果、取消和源文件删除后的权限状态沿用“我的团队任务”。成员资格或提交授权被撤销时，已打开的创建表单会在下次权限核对后关闭。

## 恢复转写报价

第一次获取报价时，浏览器先保存该授权的请求编号和选定价格。刷新后只会查询原任务。若报价回执丢失，点击“核对原转写报价”会使用同一请求编号、价格、输入授权和调用编号。恢复记录按用户、所有者、授权、调用和团队预算隔离。它不保存音频或会话密钥。

确认预留前可以在报价过期或无法继续核对时显式放弃该报价，再按当前价格获取。提交可能已经送达后，界面会保留原报价和业务键以查询结果。仍需停止执行时可撤回原音频授权。授权结束后的“完成”会清除本机对应的恢复记录。
