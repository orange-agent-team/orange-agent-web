# 个人积分与预算页面

入口`/account`，位于当前用户登录门禁之内。页面显示可用积分、任务预留、待确认收益及个人预算分页，创建预算不会充值、预留钱包或修改余额。完整模型任务页面、团队预算治理、支付和云Agent未因本页完成。

所有金额先以严格schema及i64范围检查，再使用BigInt计算；1积分=1,000,000微积分。输入最多六位小数，不使用浮点数转换，不截断超限值。钱包和预算列表同时核对响应user_id/owner_id；身份变更、401/403清除原页面上下文，异常余额或预算不变量拒绝显示。

创建前将原scope、上限和幂等键保存在按user/owner隔离的sessionStorage中，不存Cookie、CSRF或密码。未知结果及页面重载后只允许继续同一意图，不自动换键；损坏或无法保存的意图禁止发起新的创建。请求有15秒客户端等待上限；超时不意味着后端没有效果，仍保留原键。关闭整个标签页会结束sessionStorage生命周期，已创建预算以服务端列表/详情为准，不承诺跨设备恢复。

用户身份与account契约在`docs/contracts/`内独立固定，来源提交与每个文件摘要写入snapshot.json。构建只读本仓库快照，不隐式导入相邻服务端未提交文件。

验证分开记录：`node scripts/check-account.mjs`执行客户端边界、构建和真实Chrome/API替身测试，覆盖精确金额、等待上限、断连重载、原键去重、损坏意图、身份清屏及窄屏不遮挡。真实Keycloak/HTTPS/Rust/PostgreSQL由服务端`check-user-identity.py --web-repo <本仓库>`验证，新增创建、同ID重试、余额不变和另一用户404。替身不代表真实登录、支付或跨浏览器认证。

正式源码11项客户端测试、构建、3项Chrome替身和4项真实OIDC/用户流程通过，WEB-ACCOUNT-001及USER-OIDC-001的源码绑定证据已刷新。整个项目和原父任务没有因此全部完成。

账户导航中的「支持授权」读取当前会话拥有的已发布纯文本文件元数据。用户按文件和版本选择，填写工单和用途，选定 15 分钟、1 小时或 24 小时后确认。授权记录使用服务端生成的编号，撤销后刷新页面可再次查证。未确认的请求可以在原页面使用原幂等键核对；重新进入页面时应先查看已有记录。浏览器不保存文件正文或支持用途到持久缓存。

「托管运行」从 /agent 进入。页面读取平台 Host 活跃状态和个人工作区占用，用户选择根预算、输入与期限后提交。待处理请求在当前会话存储中只记录编号、摘要和不可变文件版本，刷新后可以找回或撤回原请求。取消后分别展示 Run 状态和工作区回收状态。模型步骤和工具审批使用随仓库固定的云契约快照。

专用开发 Host 已接入时，工作区就绪表示真实 gVisor 进程已持有对应输入版本。页面分别展示用户取消和物理回收；控制面只有在核对原分配的实际回执后才报告已回收。真实浏览器验收使用三个独立状态观察记录，后端另核对 Host 日志、输入摘要与 Linux 清理凭据。

选择「模型回复」时，用户还需选择平台上当前可用的推理价格和最大输出单位。Host 准备完成后，可以查询真实报价；模型 Job 在用户确认展示的最高费用后才提交。页面会按原 Run 核对已经提交但未收到回包的确认。已结算的纯文本答复可从「模型步骤」读取。原输入删除后，页面清除答复，直接产物读取也受同一来源约束。报价、账务和工作区回收是独立事实。[托管模型契约快照](contracts/cloud-agent.openapi.json)

模型模式下可选择允许模型申请查看托管工作区根目录。该选择记录一个限定范围的能力。实际模型提出操作后，用户在「工具审批」中查看参数、工作区、模型提交及审核摘要；批准或拒绝针对该次操作生效。撤销后不再显示旧的参数和目录结果。结果记录区分已完成、未执行和执行结果待核对。默认在该次工具结果提交后结束。创建 Run 时同时启用续轮的用户可以准备第二轮输入，查看并确认新的费用上限，再由模型根据目录结果回答。页面展示两轮各自的报价、作业、已结算费用和总额。撤销目录授权后，派生内容随刷新隐藏。
